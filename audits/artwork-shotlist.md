# Artwork shot list (Pass E)

The site has **65 image slots**, but many of them reuse the same piece. The Home, Work and Shop pages pull from the case studies. That makes **about 49 unique images**. Start with **Priority 1**: those 11 images fill the first screen of every page.

## File specs
- **Format:** JPG for photos and paintings, PNG for flat graphics and logos. Send the original, uncropped file. I'll crop it to each slot and make web-sized copies.
- **Size:** long edge at least **2400px**. Wide banners (21:9) at least **2800px** wide.
- **Colour:** sRGB if you can. Otherwise I'll convert.
- **Names:** anything readable, e.g. `vnce-turnaround.jpg`. Add the year and medium if you know them, because they go on each plate's caption ("Pl. 03 · VNCE, turnaround · 2023 · ink and digital").
